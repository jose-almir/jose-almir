## Featured Projects

- **[Sol-e](https://github.com/jose-almir/sol-e)**: A tool for extracting BibTeX references. It automates metadata collection from SBC Open Lib articles to ease the lives of researchers. Built with `TypeScript`, `ExpressJS`, and `Angular`.
- **[Dafont Downloader](https://github.com/jose-almir/dafontdownloader)**: A `Python` script for automated Dafont font downloads. Solves a common need with a simple and direct solution.
